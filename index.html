Sobre mim

Desde 2022, sou estudante de análise e desenvolvimento de sistemas, e minha jornada nessa área começou quando comecei a trabalhar como auxiliar administrativo. Foi lá que descobri minha paixão por automatizar processos. Adorava criar planilhas automatizadas para agilizar as tarefas diárias. Sempre que possível, buscava formas de tornar os processos mais eficientes. Minha vontade de automatizar tudo o que pudesse me levou a desenvolver soluções por conta própria. Fui explorando diferentes linguagens de programação e técnicas de desenvolvimento, e foi assim que me apaixonei pela área de desenvolvimento de software. A oportunidade de criar soluções inovadoras para problemas complexos me encantou profundamente. Desde então, tenho buscado constantemente aprimorar minhas habilidades técnicas e expandir meu conhecimento nesse campo em constante evolução.

Projetos

Formulário para curriculos

Desenvolvi um projeto para o cadastro de currículos no banco de dados do hospital onde trabalho, utilizando um formulário personalizado. A solução foi criada para otimizar o processo de recebimento e organização dos currículos, garantindo eficiência no armazenamento e fácil acesso às informações. O foco principal foi oferecer uma interface prática e funcional para facilitar o envio de currículos pelos candidatos.
